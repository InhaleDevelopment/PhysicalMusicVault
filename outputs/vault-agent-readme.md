# Physical Music Vault On/Off

There is one Windows control: `Vault On-Off.cmd`.

- Double-click it while the dashboard is off to start the dashboard in the background and open it.
- Double-click it while the dashboard is on to stop it.
- Local music-folder changes trigger an immediate sync, with a 10-minute reconciliation while the dashboard is on.
- Wanted-album availability scanning runs every 30 minutes when automation is enabled. The default search provider is free and needs no API key.

The dashboard address is `http://localhost:8787/`.
